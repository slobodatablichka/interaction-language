# Rules / Правила

[English](#english) | [Русский](#русский)

## English

### 1. Do not create unnecessary entities

Create a new term, command, status, rule, file, or structural level only when it solves a real need.

Before adding one, ask:

- can an existing element do the job;
- will this reduce human effort;
- will this reduce ambiguity for AI.

If not, do not add it.

### 2. Real work comes first

Prefer:

`use → observe → name → refine`

The language should grow from practice, not from an invented taxonomy.

### 3. Use the smallest sufficient formalism

Add structure only when it improves understanding or predictability.

### 4. Prefer natural language

Do not invent special syntax when an ordinary human expression can carry the meaning clearly enough.

### 5. Meanings should be operational

For every language element, it should be clear what changes in human or AI understanding or action when it is used.

### 6. Keep the language alive

Elements may be clarified, merged, renamed, or removed.

Existing structure is not a value by itself.

## Русский

### 1. Не плодить лишние сущности

Новый термин, команда, статус, правило, файл или уровень структуры создаётся только при реальной необходимости.

Перед добавлением спросить:

- нельзя ли использовать уже существующее;
- уменьшит ли это усилия человека;
- уменьшит ли это неоднозначность для ИИ.

Если нет — не добавлять.

### 2. Реальная работа первична

Предпочтительный путь:

`использовать → наблюдать → назвать → уточнить`

Язык должен возникать из практики, а не из заранее построенной классификации.

### 3. Использовать минимально достаточную формализацию

Структура нужна только там, где она улучшает понимание или предсказуемость.

### 4. Предпочитать естественный язык

Не создавать специальный синтаксис, если обычное человеческое выражение уже можно сделать достаточно однозначным.

### 5. Значение должно быть операционным

Для каждого элемента языка должно быть понятно, что меняется в понимании или действиях человека и ИИ при его использовании.

### 6. Язык остаётся живым

Элементы можно уточнять, объединять, переименовывать и удалять.

Сохранение старой структуры не является ценностью само по себе.
