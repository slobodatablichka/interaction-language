# Interaction Language

[English](#english) | [Русский](#русский)

## English

**Interaction Language** is an open project for developing a practical language of interaction between people and AI.

Goal:

> reduce human effort while increasing the precision with which AI understands intent.

The language grows from real work rather than from a finished system designed in advance.

Working path:

`real interaction → recurring pattern → formulation → practical test → adoption, revision, or removal`

Individual projects may extend the common language with project-specific vocabulary:

`common language → project language → current context`

### Files

- `README.md` — project purpose;
- `RULES.md` — rules for developing the language;
- `INTERACTION-LANGUAGE.md` — the current working language.

The project is at an early stage and open to contributors.

## Русский

**Interaction Language** — открытый проект по разработке практического языка взаимодействия человека и ИИ.

Цель:

> уменьшать усилия человека и повышать точность понимания его намерений ИИ.

Язык развивается из реальной совместной работы, а не проектируется заранее как законченная система.

Рабочая схема:

`реальное взаимодействие → повторяющийся паттерн → формулировка → проверка в работе → принятие, изменение или удаление`

Отдельные проекты могут расширять общий язык собственным специализированным словарём:

`общий язык → язык проекта → текущий контекст`

### Файлы

- `README.md` — назначение проекта;
- `RULES.md` — правила разработки языка;
- `INTERACTION-LANGUAGE.md` — текущий рабочий язык.

Проект находится на начальной стадии и открыт для соучастников.
